# centimentalcomics

A webcomic site featuring comics about art and internet. This project is built with Next.js and uses a headless API to serve comic content.

![centimentalcomics](https://s3.us-east-2.amazonaws.com/centimentalcomics.com/assets/images/about.jpg?height=300&width=600)

## Features

- Responsive comic display with pagination
- Individual comic pages with navigation
- About page with artist information
- SEO optimized with metadata for better search engine visibility
- Progressive Web App (PWA) support
- Server-side rendering for improved performance

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Custom CSS with Skeleton CSS framework
- **Fonts**: Google Fonts (Coming Soon)
- **Image Optimization**: Next.js Image component
- **Deployment**: Vercel (recommended)
